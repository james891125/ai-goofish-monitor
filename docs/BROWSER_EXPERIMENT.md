# 實驗逐件瀏覽（非官方授權來源）

這是使用者選擇啟動的本機實驗工具，不是正式蝦皮 API，也不保證網站允許或能成功讀取。低頻、本人帳號與正常登入都不等於取得平台自動化存取權。

蝦皮臺灣[服務條款](https://help.shopee.tw/portal/4/article/77267)第 3.1、6.2(k) 條對監視、複製及非官方軟體使用平台有限制，沒有列出低頻例外；[購物安全說明](https://help.shopee.tw/portal/4/article/80055)亦提示帳戶限制風險。這是平台條款與帳號風險，不應自行推論為已證明違法。使用前請自行確認適用權限；工具的風險勾選不會授予平台許可。

## 可做與不可做

- 關鍵字模式：開啟一般可見的搜尋頁，只取首個已載入畫面中的有限商品連結，再依序瀏覽。沒有翻頁、無限捲動或批量背景工作。
- 網址模式：接受 1 至 5 個正常蝦皮臺灣商品網址；移除追蹤參數，不接受短網址、站外網址、登入網址或私有接口。
- 每批最多 5 件，間隔可設 60 至 300 秒，固定間隔、單一序列，沒有隨機偽裝、平行請求、代理輪替或重試。
- 標準可見瀏覽器、獨立臨時工作階段，由人自行登入；不接管日常瀏覽器個人資料，不開 CDP 遠端除錯，不收集／匯入／匯出 Cookie。
- 只讀已呈現的商品標題及可明確認定的 NT$／TWD 價格。只有 `$`、多個無法區分的價格或未知欄位時停止，不虛構匯率、不猜價格。
- 遇到登入牆、驗證碼、反機器人提示、401／403／429、非預期跳轉或缺少必要欄位時停止，不自動重試，也不提供繞過方式。
- 不下載圖片、不讀隱藏頁面狀態、不呼叫私有 API、不蒐集賣家歷史或推測信用。收集器本身不呼叫 AI 或 Discord。

**關鍵字發現尚未完成真實蝦皮頁面驗證。** 離線合成頁面測試只證明程式在明確條件下的邏輯與停止行為，不能保證蝦皮頁面提供必要欄位，或將此版本說成可用的全站監控。網址模式也不是關鍵字監控的替代驗收。

瀏覽器限制：HTTP 重新導向可能在 Playwright 收到事件前已由瀏覽器發出，不能保證每一跳都在網路層被攔下。程式檢查回應、Location 與實際跳轉鏈，自動收集階段一旦有主文件重新導向就停止，不讀取該商品，也不繼續下一件；手動登入階段只容許同站流程。這不是網路隔離工具，不能把「遇跳轉停止」解讀為「不可能發出任何重新導向請求」。

## Windows 操作

先依 README 啟動主程式。實驗工具是選用依賴，普通啟動主程式或 Docker 不會自動安裝或執行。雙擊實驗捷徑時才會在需要安裝時另外詢問，未輸入 `yes` 不安裝。

若不想輸入命令，可雙擊專案中的 **`實驗瀏覽收集.cmd`**，選取已下載的設定 JSON。工具會另選全新輸出檔名，仍保留風險確認及本人登入；必要依賴需由使用者確認安裝，不能繞過執行政策。詳見 [雙擊操作說明](WINDOWS_DOUBLE_CLICK.md)。以下命令流程仍可選用。

1. 管理介面進入「資料來源」的實驗區，填寫關鍵字或商品網址、每批數量及間隔，下載 `browser-request.json`。將檔案放在專案根目錄。設定檔不含帳密。

   第一次建議只設 **1 件、60 秒**，先確認網站是否允許這次流程。也可複製 `examples/browser-collect.example.json` 為 `browser-request.json` 並修改關鍵字。即使只有 1 件，首頁→搜尋頁→商品頁之間仍有等待，並非立即出結果。
2. 在專案根目錄開另一個 PowerShell，安裝選用的官方 PyPI 套件：

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements-browser.txt
   ```

3. 使用電腦已安裝的 Microsoft Edge：

   ```powershell
   .\.venv\Scripts\python.exe scripts/browser_collect.py --request browser-request.json --output browser-results.json --channel msedge
   ```

   若只安裝 Chrome，可明確指定 `--channel chrome`。不會自行改用另一個瀏覽器避開封鎖。`chromium` 選項需要事先以 Playwright 官方安裝方式安裝相符瀏覽器；Windows 不需要為本流程額外下載 Chromium。

4. 閱讀終端機的風險提示。只有自己確定要繼續才確認；在新開啟的可見瀏覽器中自行登入，完成後回終端機確認。不要把帳密貼到終端機、管理介面或對話。
5. 等候逐件流程完成。可以用 Ctrl+C 停止。若出現阻擋或驗證，停止這次實驗，不重新登入、換帳號、換代理或反覆執行來規避。
6. 回到資料來源實驗區，選取 `browser-results.json`。分別確認資料使用權及風險後匯入。若本批途中停止，只能匯入停止前確實完成的商品；空結果不應當成成功。
7. 建立資料來源為「實驗瀏覽快照（手動更新）」的任務，最多 5 件、頁數 1、僅手動執行，填寫購買需求並使用 AI 分析。先在設定頁填寫自己的 AI 端點、模型與 Key；未設定或回應無效會顯示失敗，不能以關鍵字結果代替 AI。

**管理介面的「執行」不會重新瀏覽網站。** 要發現新商品或更新價格，須由使用者重新啟動收集器、匯入新快照，再執行分析；目前沒有無人值守或定時瀏覽器監控。

收集器不會覆寫既有輸出。如果 `browser-results.json` 已存在，請改用新檔名，例如 `--output browser-results-2.json`，再匯入對應檔案；不要為了重跑而刪除唯一一份舊結果。圖片並未收集或自動交給 AI；若圖片對判斷必要，這份快照會有明確證據缺口，需另行提供有使用權的圖片資料並設定分析選項，不能假裝已看圖。

## 隱私、資料與故障

- 關閉工具會結束臨時瀏覽器工作階段。程式不保存登入狀態供下次使用，不會使用原有 Chrome／Edge 設定檔。
- 輸出只有標準商品欄位、來源與安全化狀態，不含 Cookie、登入畫面、原始 HTML、截圖或完整例外。自訂輸出路徑也需自行妥善保存，不要公開提交。
- `browser-request*.json`、`browser-results*.json` 已加入 Git 忽略規則。這不是對任意自訂檔名的自動保護；請勿將私有收集資料放入 Git。
- 系統保留既有快照及商品價格歷史，不清空舊資料。匯入相同商品 ID 更新內容，執行任務後才記錄新價格。
- 快照的 `collected_at` 必須包含時區，保存原始採集時間；重新匯入或分析不會改成今天。匯入、分析及價格歷史的記錄時間另行保存，不能把它們當作網站剛更新價格。
- 商品可能已下架、價格受變體／優惠影響，頁面也可能改版。工具寧可停止，也不把不確定數字當成可購買報價。
- 新功能的真實蝦皮登入、搜尋與商品 DOM 成功率，以及 Windows 實機整套操作仍待另外驗證；既有版本的 Windows 通過不能當作這項新功能已通過。
