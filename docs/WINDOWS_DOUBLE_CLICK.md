# Windows 11 雙擊啟動

本功能供下載 ZIP 後在 Windows 11 本機操作。主程式仍為「等待資料來源授權」；能開啟介面不代表取得蝦皮全站搜尋授權。

## 第一次使用

1. 安裝官方 Python 3.11 以上版本（勾選加入 PATH）及 Node.js 22.12 以上版本（包含 npm）。安裝後重新開啟檔案總管視窗。
2. 將 ZIP **完整解壓縮**到本機可寫入的資料夾，不要在壓縮檔預覽內執行。支援中文、空白及 `!`、`&` 的資料夾名稱。
3. 雙擊根目錄的 **啟動蝦皮監控.cmd**。不需要自行輸入命令。
4. 尚未有 `.env` 時，工具只會從 `.env.example` 建立新檔，然後開啟記事本。設定自己的 `WEB_USERNAME` 與至少 12 字元的 `WEB_PASSWORD`，儲存後回啟動視窗按 Enter。既有 `.env` 不會覆寫。
5. 第一次會安裝 Python 套件並建置前端，需要網路。看到本機服務就緒後，才會開啟 `http://127.0.0.1:設定的連接埠`。使用剛設定的帳密登入。

**以後只要再次雙擊「啟動蝦皮監控.cmd」。** 依賴與前端來源沒有改變時，不會重跑安裝與建置。

請保留啟動視窗：它顯示記錄；按 Ctrl+C 停止自己啟動的服務。結束或出錯後，視窗會停在「按任意鍵繼續」，不會把錯誤一閃而過。若系統詢問是否終止批次工作，按 Y 即可。

## 重複點擊、連接埠與資料

- 同一份專案已在安裝或啟動時，第二次點擊只提示查看原視窗，不會再啟動 pip、npm 或第二個服務。
- 同一連接埠的 `/health` 同時回傳 `status: healthy` 及 `application: shopee_tw_monitor` 才視為本系統，就緒後只開啟其本機網址。檢查不送帳密、不使用系統代理、不跟隨重新導向。
- 連接埠被其他程式使用、回應不符或仍未就緒時會停止，不會終止既有程式，也不會偷偷換連接埠。先查看原視窗；需要時自行調整 `.env` 的 `SERVER_PORT`。
- `.env`、資料庫及匯入檔都不會因啟動而清空。不要把 `.env`、帳密、API Key 或 Webhook 放進截圖或公開回報。
- 更新版本請保留舊資料夾做備份；不要刪除舊版資料後才升級。啟動器不搬移或覆寫資料。

## PowerShell 被封鎖時

兩個 `.cmd` 都只以 `-NoProfile -File` 執行同一份 `start.ps1`，並遵守目前的 PowerShell 原則。封鎖後不會改走 Python 或其他執行方式。

- **RemoteSigned，而且不是組織原則管理：** 僅在確認 ZIP 來源及 `start.ps1` 內容可信後，在檔案總管右鍵 **start.ps1 → 內容 → 解除封鎖 → 套用**，再雙擊 `.cmd`。這只處理你核准的單一腳本。沒有此選項、內容不可信或仍被封鎖時，請停止並詢問管理員。
- **AllSigned、Restricted 或組織原則：** 請管理員提供符合原則、核准或簽署的腳本。本工具不會降低原則或要求關閉保護。
- 不要關閉 SmartScreen、繞過群組原則，也不要複製網路上用來略過執行限制的命令。若出現 Windows 安全警告，先確認來源並依組織規定處理。

## 選用：雙擊實驗瀏覽收集

此步驟不是主程式啟動的必要條件。蝦皮條款沒有低頻自動化例外，登入成功也不代表有權自動化；可能受到驗證、存取限制或帳號凍結。完整限制見 [BROWSER_EXPERIMENT.md](BROWSER_EXPERIMENT.md)。

1. 依上述文件先準備既有的 `browser-request.json` 需求檔，並確認有權存取。工具不會替你捏造需求或自動開始登入。
2. 雙擊 **實驗瀏覽收集.cmd**。若尚未安裝選用依賴，會詢問是否安裝 `requirements-browser.txt`，只有輸入 `yes` 才安裝。此時若主程式仍在執行，請先在主程式視窗按 Ctrl+C；安裝完成後兩者可同時使用。
3. 在檔案選擇視窗選取既有 JSON。若系統沒有檔案選擇元件，可輸入檔案完整路徑；空白或關閉選擇視窗會取消。
4. 每批仍需在原工具內輸入 `yes` 確認風險，再到新開啟的 Edge 手動登入，並再次輸入 `yes` 才開始讀取。本捷徑不代填登入資料、不加上自動略過風險確認的參數。
5. 結果另存為 `browser-results-日期時間-識別碼.json`，不覆寫既有檔案。將需要的資料透過主介面的匯入功能匯入；不會自動匯入或排程。

既有單批鎖、最多 5 筆、60–300 秒間隔、遇驗證／封鎖立即停止等保護全部保留。沒有安裝 Edge 或無法啟動瀏覽器時會停止，不會自動下載替代瀏覽器。環境更新期間不允許同時收集，收集中也不會修改共用套件。

## 手動唯讀檢查與測試範圍

進階使用者仍可使用 `start.ps1 -CheckOnly`。這只檢查既有環境、設定與前端產物，不安裝依賴、不新增 `.env`、不啟動伺服器，也不開啟瀏覽器；不可與其他模式合用。

自動測試包含離線健康端點、重複啟動、檔名與參數隔離、既有設定保護、PowerShell 原則拒絕時無替代啟動，以及 Windows 上實際執行 `.cmd`／PowerShell 的測試。測試不開啟真實蝦皮、不進行手動登入；真實 Windows 11 桌面瀏覽器與安全提示仍需使用者在自己的電腦確認。
