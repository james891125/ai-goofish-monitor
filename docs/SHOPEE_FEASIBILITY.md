# 臺灣蝦皮資料來源可行性與上線門檻

評估日期：2026-11-10。狀態：**等待資料來源授權**。

本版本可以執行模擬搜尋、經確認具有使用權的資料匯入、篩選、AI 分析、排程與通知。**尚未驗證合法的臺灣蝦皮全站跨賣家關鍵字自動搜尋，也沒有實作該功能。** 取得 Cookie 或能在瀏覽器登入，不代表取得自動化擷取權限。

## 架構與功能差距

- 以 `ProductProvider.search(ShopeeTask)` 將取得資料與 AI／持久化解耦。正規化模型只接受明確的新臺幣價格，不猜私有 API 的價格倍率。
- `MockProvider`、`ImportProvider` 可運作；`ShopeeProvider` 固定回報 `authorization_required`，無任何未授權網路請求。
- 能力狀態回傳搜尋、價格、類別、新舊、地區、賣家類型與廣告能力。來源沒有證據的欄位維持 null；要求特定條件時未知資料不通過該篩選。
- 原閒魚 Cookie 擷取擴充功能、登入態／輪換、爬蟲路由不掛載於新應用。歷史原碼保留做資料相容與回歸參照，不能作為蝦皮存取方式。
- 沒有授權憑證，因此沒有假裝成功的 OAuth 或重新授權按鈕；介面呈現來源狀態、空到期日與所需下一步。
- 商品網址只能作為已提供商品的外部連結，不會觸發瀏覽器登入、擷取或圖片下載。
- 匯入資料不會自行更新：價格變更需重新匯入；排程搜尋的是當前匯入快照。

## 正式上線前必須取得並驗收

1. 向官方或具可驗證授權鏈的供應商取得臺灣跨賣家關鍵字搜尋資格、資料範圍、正式 API 文件與測試帳號。
2. 確認可保存的商品／賣家欄位、保留期限、AI 處理／圖片處理／Discord 分享權限、刪除義務、費用及配額。
3. 依官方方式實作 OAuth／簽章／到期與重新授權，不記錄 token、Cookie 或密碼。
4. 為 adapter 補上欄位映射、分頁、去重、單位、429/Retry-After、授權失效、逾時與停止重試測試；不以代理、Cookie 輪換或驗證碼繞過限制。
5. 在授權環境實測真實關鍵字、AI 合法 JSON、Discord 接收、長時間排程與 Windows/Docker 部署。
6. 完成主要測試與安全檢查後，才可把「等待資料來源授權」改為正式可用；不要只改狀態文字。

Cookie 外掛不是本版上線解法。不得安裝收集帳密、把 session 傳給未授權第三方的工具，也不得照搬閒魚擴充功能改網域。
