# 蝦皮商品清單（精簡版）

輸入關鍵字，整理成一張 CSV：**品名、狀態（全新/二手…）、規格、記憶體、儲存容量、保固、價格、出貨地、賣場、已售、上架日期、連結**。

不需要資料庫、排程、推薦分數。只在你的電腦上執行，想看的時候開起來跑一次就好。AI 是選用的。

> 本專案僅供個人學習與自用。請自行確認使用方式符合蝦皮的服務條款，並放慢使用頻率。見 [DISCLAIMER.md](DISCLAIMER.md)。

## 需要先安裝

- [Python 3.10 以上](https://www.python.org/downloads/)（Windows 安裝時勾選「Add python.exe to PATH」）
- Google Chrome（或 Edge）

## 啟動

| 系統 | 做法 |
| --- | --- |
| Windows | 雙擊 `start.bat` |
| macOS / Linux | `python3 start.py` |

第一次會自動建立 `.venv` 並安裝套件，然後開啟網頁介面 `http://127.0.0.1:8765`。

## 第一次使用

1. Chrome 開 `chrome://extensions` → 開啟「開發人員模式」→「載入未封裝項目」→ 選本專案的 `chrome-extension` 資料夾。
2. 開 `https://shopee.tw` 並登入，點擴充功能「提取登入狀態」→「複製到剪貼簿」。
3. 在網頁介面的「登入狀態」貼上並儲存。
4. 輸入關鍵字、按「開始搜尋」。蝦皮要求驗證時，在跳出的瀏覽器視窗完成即可，程式會自動繼續。

## 欄位怎麼來的

| 欄位 | 來源 |
| --- | --- |
| 品名、價格、出貨地、賣場、已售、上架日期 | 搜尋結果直接有 |
| 狀態、規格、記憶體、儲存容量、保固 | 用規則從標題（與描述）抽出，抓不到就留空，**不猜測** |

- 「規格」是通用欄位：晶片或型號（M4 Pro、RTX 5070 Ti）、尺寸（46mm、14吋）、GPS 或 LTE。只從標題判斷。
- **整欄都空白的欄位不會出現在 CSV 裡**。例如搜尋手錶時沒有任何商品有記憶體，就不會有「記憶體」這一欄。
- 容量是啟發式判斷：同時出現兩個容量（例如 `16G/512G`）時，小的當記憶體、大的當儲存。

### 要不要進商品頁取得描述（補詳情）

標題通常不夠，所以有三種模式：

| 模式 | 行為 |
| --- | --- |
| `off` | 只看標題。最快，一頁只有一個請求，被要求驗證的機會最小 |
| `auto`（預設） | 只有標題缺「狀態」或「容量」的商品才進商品頁補 |
| `all` | 每件都進商品頁，保固資訊最完整，也最慢 |

### AI 整理（選用）

| 模式 | 行為 |
| --- | --- |
| `off`（預設） | 只用規則 |
| `on` | 規則抓不到的欄位，才用 AI 的結果補上（規則已有值就不覆蓋） |
| `compare` | 規則與 AI 並排，多出 `AI_狀態…` 欄位和「差異欄位」，並印出每個欄位的一致／不同統計 |

AI 只送文字、不送圖片，每個請求放 20 件商品一起處理，所以用量很低。支援 Google Gemini、OpenRouter、OpenAI（設定頁一鍵帶入），使用 `max_completion_tokens`。

## 濾掉不要的商品

- **價格範圍**：最有效。搜尋時會交給蝦皮篩選，抓回來後程式會再檢查一次（多規格商品以最低價為準）。
- **排除配件**：預設開啟，標題含保護貼、錶帶、底座等詞的不列入。命令列用 `--keep-accessories` 關閉。
- **額外排除的詞**：自己加，標題含任一個就不列入。命令列用 `--exclude "殼,膜,線"`。
- **排除標題沒包含關鍵字的商品**：預設開啟。

## 看幾頁

一頁約 60 件。預設 3 頁，最多 10 頁。蝦皮可能在換頁時再次要求驗證，我無法保證不會；建議先從 1 到 3 頁開始，被要求驗證就完成它。每次成功執行後，程式會把最新的蝦皮 Cookie 存回登入檔，之後比較不容易再被要求驗證（不保證）。

## 傳到 Webhook

設定頁填入 Webhook 網址後，結果區按「傳送到 Webhook」，或命令列加 `--webhook`。CSV 會以檔案附件的方式用 multipart 上傳。Discord Webhook 可直接使用；其他 Webhook 需要接受檔案上傳。

## 命令列

```bash
python -m shopee_lite run "mac mini m4" --pages 3 --max-price 30000
python -m shopee_lite run "mac mini m4" "macbook air m3" --detail all --ai compare --webhook
python -m shopee_lite ui
```

結果存在 `output/`，CSV 以 UTF-8 BOM 編碼，Excel 直接雙擊可正確顯示中文。
